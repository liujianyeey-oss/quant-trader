# 策略 v2 设计文档：资产选择 / 仓位管理 / 板块轮动的规则化

> 2026-11-08 起草。状态：**已评审（用户已确认决策点：黄金卫星 20%、目标波动 10% 邻域 8/10/12、门槛不变），未实施**。
> 设计原则：一切选择收归策略内部规则；治理层只设风险红线，不替策略选资产；每个新模块必须自带证据链（全历史回测 + 参数邻域高原 + 相位中位数 + 含成本净收益）才能上线；规则"少而钝"，宁可迟钝不可精细。

---

## 背景与动机

当前系统三个选择暴露在策略外部，成为运气/治理的函数：

1. 防守资产写死 518880 黄金——网格寻优撞上 2024-2025 黄金牛市的产物，审计证实两策略 55~57% 历史年化来自这一个选择；
2. 仓位管理只有 staggered 有雏形（0.12 波动预算），momentum 满仓/空仓硬切换；
3. 进攻池为 4 只宽基 ETF（510300/510500/159915/588000），相关性极高，谈不上真正的轮动。

## 模块 D1：防守池轮动（替代写死单一防守资产）

### 池与分层

| 候选 | 角色 | 结构特征 |
|---|---|---|
| 511880 货币ETF | 最终兜底 | 波动≈0.1%，正 carry，零相关 |
| 511360 短融ETF | 核心候选 | 波动≈0.1%，正 carry |
| 511010 5年国债ETF | 核心候选 | 波动≈0.6%，利率下行期权 |
| 511260 10年国债ETF | 核心候选 | 波动≈1.3%，久期风险（利率急升可回撤 3-5%） |
| 518880 黄金 | 卫星候选 | 波动 17-20%，零 carry，风险资产属性 |

### 规则（草案，全部参数待回测验证）

- **核心仓（防守仓位的 80%）**：仅允许 60 日年化波动 <3% 的候选（黄金被规则自动排除，无需人工投票）；池内按 20 日动量排名持有第 1 名；排名差 <1pp 或 <5 个交易日不切换（迟滞防抖）；兜底 511880。
- **卫星仓（防守仓位的 ≤20%）**：仅当黄金同时满足（收盘 > MA60 且 20 日动量 > 3%）时持有 518880；任一条件破坏即切回核心仓第 1 名。作用：保留商品牛市的可选项，但仓位和条件都由规则限定。
- 切换频率上限：每周至多一次（与 staggered 节奏对齐）。
- 上市日缺失处理：沿用引擎现有延期/置零机制并在报告中标注。

### 验证计划

- 全历史（2019 起）三对照：死守黄金 / 死守货币 / 防守池轮动，输出年化/回撤/夏普/卡玛 + 防守段归因；
- 参数邻域：动量窗口 10/20/30/60、迟滞阈值 ±50%，须为高原而非孤峰；
- 5 个调仓相位中位数报告；含成本（万1+最低5元+滑点0.1%）净收益；
- **通过门槛**：轮动脉络的夏普 ≥ 死守黄金，且回撤 ≤ 死守黄金；否则不上线。

## 模块 D2：波动目标仓位（全系统统一的仓位层）

### 规则（草案）

- **目标波动**：组合年化 10%（已确认；邻域 8/10/12% 待验证）。
- **实现波动估计**：持仓标的 20 日 EWMA 波动（λ=0.94）。
- **仓位系数**：scalar = min(1, 目标波动 / 实现波动)，无杠杆；每日计算，仓位变化 <10% 不动（防抖）。
- **回撤联动**：组合净值距峰值回撤 >10% → scalar 再 ×0.5；>15% → ×0.25 且仅允许防守池。回撤修复至 <5% 后逐档恢复（恢复速度慢于降档速度，防 V 型反复）。
- momentum 从满仓/空仓硬切换改为 scalar 缩放；staggered 的 0.12 组内波动预算与本层合并为同一口径，消除双重标准。

### 验证计划

- 全历史对照：现口径 vs 波动目标口径，重点看 2019-2021 趋势段是否被过度降仓（机会成本）与 2022/2024 回撤段是否有效减仓；
- 目标波动 8/10/12% 邻域；成本后净收益；换手率增量必须量化并<20%。

### 规则（草案）

- 打分：20 日动量与 60 日动量等权合成（与 momentum 现有口径兼容）；

- **特别警示**：扩池增加选择自由度 = 过拟合面积增大，若扩展池夏普提升 <10% 且换手增 >50%，放弃 D3。

## 治理层（收口后的唯一职责）

- 风险红线：组合最大回撤预算 15%（触及触发 D2 回撤联动）、单一进攻标的权重 ≤50%、防守卫星仓 ≤20%；
- 变更纪律：任何规则/参数改动 = 全历史回测 + 稳健性网格 + 1 个月影子运行 → 才允许进 config；历史台账分段封存，不涂改；
- 季度评审：防守池结构标准复核（波动/相关性/carry）、参数有效性复核、LESSONS 回读。

## 修订记录

### 2026-11-08 治理决策：D1 验收门槛参照系修订（用户拍板，选项 A）

**S1 回测结果**（reports/d1_defensive_rotation_backtest_20261108.md）：D1 轮动 vs 死守黄金——夏普 0.46/0.60 vs 0.80/1.07，四项全败，按原门槛不过门。

**门槛修订**：参照系从"死守黄金"改为"死守货币 511880"（结构纯净基线）。理由：死守黄金的夏普是 2024-25 黄金牛市的后视污染产物，任何黄金 ≤20% 的规则在样本内数学上不可能追平，用它当门槛等于奖励运气。修订后 D1 通过（0.46/0.60 vs 货币 0.44/0.56），且附带黄金卫星期权与回撤收敛。

**伴随的预期重置（正式口径）**：剥离运气后，本系统真实预期 = 趋势引擎年化约 6-10% + 防守期约 2% carry；历史回测的 13-18% 含黄金牛市馈赠，不作为预期依据。

**S1 结论**：D1 进入 S2 影子运行（1 个月，2026-11-09 起至 2026-12-08 评审）。

### 2026-11-09 S5/S6 阶段结论（reports/s5_s6_review_20261109.md）

**S5（trend_ma ensemble 验证）**：孤峰成立——momentum 40/50/60 单调递增（锚定与相位中位同序 +6.1/+10.3/+13.3%），叠加审计的 120 日构成单峰；staggered 为高原（12.7~13.5%），维持 60。多数投票 ensemble 被否决：二元投票 ≥2/3 数学上塌缩为"收盘≥三条均线中位数"≈MA50，实测与 trend_ma=50 逐项相同，零稳健性增益。趋势窗口敏感性如实披露，不用伪 ensemble 掩盖。

**S6（D3 板块轮动回测）**：**不过门，D3 封存**。致命伤是防守期占比塌缩（38%→3%）——18 只池子总有 ≥2 只站上自身 MA60，逐标的趋势门永不整体关闭，2022/2024 级回撤满仓吃下（-50.31%，破治理红线 15%）；机制对照（D3 规则×旧池 +5.30% vs 现规则 +18.49%）证明合成动量+前2等权+迟滞本身也劣于现单冠军规则。若重提板块轮动，须先解决市场级风险总闸。v2 主线剩余价值集中于 D1（影子运行中）与 D2。

### 2026-11-09 S4 阶段结论（reports/s4_d2_review_20261109.md）

**S4（D2 波动目标仓位回测）：不过门，门槛条款与机制存在设计张力，提交治理裁决。** 回撤段减仓有效（2022 窗口 -46%、2024 窗口 -82%）、换手不增反降（-49%/-9%），但趋势段（2019-21）机会成本 -52%/-27% 远超 <15% 门槛——且属恒等式级冲突（股票篮子波动 20~25% vs 目标 10% ⇒ 趋势段仓位必然 ≈0.45）。风险调整口径下 D2 表现优异（momentum tv10%：夏普 0.80→1.20、回撤 -33.5%→-8.7%）。回撤联动层在 tv≤12% 近似死代码（scalar 已把回撤压在触发线下）。staggered 叠加 D2 无增量（自带组内预算同构）。待裁决项：门槛是否改写为风险调整口径；若改写通过，推荐档位 tv10%，仅 momentum 框架采用。

### 2026-11-09 治理决策：D2 验收门槛改写（用户拍板）

**门槛修订**：D2 验收门从"回撤段减仓有效且趋势段机会成本 <15%"改写为**风险调整口径——夏普不降 + 回撤显著压缩即过**。理由同 D1 参照系修订：机会成本条款与低目标波动在数学上互斥，用趋势段收益当门槛等于拒绝一切风控层。

**裁决结果**：D2 tv10% 过门（momentum：夏普 0.80→1.20、卡玛 0.55→1.39、回撤 -33.5%→-8.7%，换手 -49%），进入影子运行（账户 shadow_d2_momentum，与实际 momentum 台账同起点，至 2026-12-08 与 D1 一并评审）。**staggered 不叠 D2**（S4 已证无增量：夏普持平 1.07、年化 -2.9pp，组内预算与组合层 scalar 同构叠加=双重压缩），此结论正式留痕。

**S4 补充说明（留档）**：回撤联动层保留为尾部保险（S4 实测 tv≤12% 时几乎不触发）；D2 影子实现 `d2.py` 与 S4 证据链 `research_v2/s4_d2_voltarget.py` 逐行同口径，等价性由 tests/test_d2.py 保证。
