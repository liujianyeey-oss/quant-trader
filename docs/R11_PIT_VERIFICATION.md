# R11 PIT 无幸存者偏差复核（interim：6 期快照）

日期：2026-09-17。状态：**interim**（真实成分快照仅覆盖 2018-06 ~ 2020-12 共 6 期，2021 年后待续采）。
数据：中证 800 历史成分（Wind 分页采集 + 装配校验，6 期 × 800 只）；差集 515 只（调出/退市）行情腾讯源 **515/515 全部拉通、零缺口**；PIT 成员行情覆盖率 1016/1016。

## 对比口径

窗口 2019-01-01 ~ 2020-12-31；两版都在**同一引擎、同一成本/涨跌停/顺延约束**下运行，只换标的池：
- **PIT 池**：信号日只用最近一期真实成分（快照间前向顺延）
- **幸存者池**：当前 717 只成分回填历史（= R11 原版口径）

## 判定

1. **M1 动量：幸存者偏差抬高了约 45pp/年**（117.3% → 72.3%，卡玛 2.64 → 1.95）。修正后仍显著跑赢指数（沪深300 同期 32.5%），卡玛与指数相当——**在本窗口它作为信号仍成立**，但 2019-2020 是动量极端友好的结构牛市窗口，**不能据此外推**，完整 17 期后重判。
2. **M2 低波：观察候选资格被推翻**。幸存者版 15.2%/0.85 → PIT 版 **2.5%/0.08**——几乎全部"边缘"来自幸存者偏差 + 窗口效应（低波在普涨牛市中天然落后）。**R11 的"M2 唯一可能真实"结论在 interim 数据下不成立**，账户 8 的预期相应下调（仍保留前向运行，因为它是零成本、无偏差的证据通道，且 2019-2020 对低波本就不友好）。
3. **方法论确认**：免费数据下的"当前成分回填"对动量类信号污染最大（每期都在买事后赢家），对低波类信号则是**制造出并不存在的收益**——这比"高估"更危险。

## 残余偏差声明（本版仍高估 PIT 侧优化空间）

- **退市股持有期损失低估**：被持有期间退市的股票，引擎无开盘价无法卖出、按最后价 ffill 估值——真实世界要承受退市归零损失，引擎只记账不实现。该缺陷使 PIT 版收益**偏高**（即真实偏差比本表更大）。
- 快照间（半年）成分按最近一期顺延，忽略期间临时调整。
- 2019-2020 单一窗口，低波/动量的相对表现受 regime 主导。
- 完整 17 期快照（至 2026-06）与更长的 2021+ 窗口待续采；本版结论标注 interim，不作为新参数决策依据。
