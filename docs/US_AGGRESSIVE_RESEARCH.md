# 美股正股激进短线：待验证研究规格

日期：2026-09-10。用户约束：美股正股、暂不加杠杆；沿用此前最多两周持仓的目标。本文给出研究算法，尚未实现美股执行模块、接入完整美股历史数据或产生美股回测收益。港股回测结果不能外推到美股。

## 研究顺序与证据

优先研究财报公布后的价格延续，再比较高波动强势股突破、突破后首次回撤。理由是财报事件有可核对的信息起点，便于区分信息冲击和普通量价信号；这不是已经证明的盈利优势。

财报后漂移的历史研究提示成本可能吃掉大部分纸面利润，尤其在不流动股票上。[原始研究作者页面](https://business.columbia.edu/faculty/research/liquidity-and-post-earnings-announcement-drift)

另有研究在其样本与交易定义下发现，2016年后的公告后交易收益与有效定价相符；因此不能把“有财报、价格跳涨”直接等同于仍有可交易超额收益，也不能将该研究外推为所有事件策略都无效。[Christensen、Timmermann、Veliyev 论文](https://arxiv.org/abs/2601.08962)

以下阈值全部是预先提出的起始假设，不是实测最优参数。三个子策略分别测试后再考虑组合，不先给它们分配虚假的最优比例。

## 共同股票池

- 按当时上市资格选择 NYSE/Nasdaq 普通股；第一版不纳入ETF、优先股、权证、OTC和ADR。QQQ/SPY仅作基准或市场指标。
- 至少120个已完成交易日，实际价格≥10 USD，前20日平均美元成交额≥5,000万；使用成交额字段，缺失时才将收盘价×成交量标为近似。
- 前14日 ATR/价格在3%—8%；拆股应先对同一窗口OHLC和成交量做一致处理，成交仍使用当时真实价格与股数。
- 不预选今天的明星股票回填历史；历史股票池须保留退市、改名、并购终止等记录。
- 首版只在常规交易时段成交。NYSE核心时段为纽约时间09:30—16:00，提前收市、夏令时、个股LULD暂停均需日历和交易状态支持。[NYSE交易规则](https://www.nyse.com/trade/trading-information)

## 三个独立信号

所有信号均在完整收盘数据可用后生成，订单最早进入下一常规交易日。信号日称t日；t+1开盘缺价或停牌则取消当次新买单，不追溯假成交。

### A：财报后强势延续，研究优先级第一

1. 核实真实发布时间。t是公告发布后的第一个完整常规交易日；盘后公告对应下一日，盘中公告也等下一完整日。
2. t日开盘相对前收盘跳涨4%—15%，全天成交量≥此前20日均量2倍。
3. t日收盘不低于开盘，且收盘位于当日高低区间上方25%。高低相等不形成信号。
4. t+1开盘不低于t日收盘减0.5 ATR，且不高于t日收盘加min(3%×收盘价,0.5 ATR)。超出即放弃。
5. 形态失效位取t日最低价减0.1 ATR。若距离拟成交价过远，按共同风险规则跳过。
6. 默认持有5日，时间硬上限10个交易日且不超两周自然日期限。

第一版是“财报时间标签+量价反应”。EPS超预期、营收超预期、上调指引只能在有当时分析师一致预期及公告原文时作为额外研究维度；缺数据时不能用最终修订值替代。

SEC提供公司提交文件与XBRL接口，但申报接收时间不应未经核对就当成新闻稿最早发布时间；保留发布时间、系统可见时间、原始来源、版本与时区。[SEC开发资源](https://www.sec.gov/about/developer-resources)

### B：高波动强势股放量突破

1. t日20日涨幅位于当时合格股票池前10%，收盘超过截至t−1的20日最高价。
2. t日成交量≥此前20日均量1.5倍，收盘位于当日振幅上方25%，突破位上方偏离≤1 ATR。
3. t+1开盘仍在突破位之上；相对信号收盘高开不得超过min(3%,0.5 ATR/收盘价)。
4. 形态失效位为突破位减0.5 ATR。默认8个交易日到期。

### C：强势突破后首次缩量回撤

1. 保存过去5个交易日中已确认的B类突破事件，在原股票上等待首次2—3日回撤。
2. 相对突破后最高收盘回撤0.5—1.5 ATR，回撤阶段均量低于突破前20日均量的70%，且所有回撤收盘均在MA20之上。
3. t日重新收于前一日最高价上方，量能≥回撤阶段均量1.2倍；t+1开盘不低于触发位，不高于t日收盘加min(3%×收盘价,0.5 ATR)。
4. 形态失效位为回撤阶段最低价减0.1 ATR。默认5个交易日到期。原始突破只能使用一次，持仓中不重复加仓。

B/C计划在当时已知的下一次财报公布前退出，不提前赌财报跳空；缺可靠预告日历的股票不进入这两类事件规避测试。

## 不加杠杆的激进仓位与退出

- 以独立USD账户净值为口径。单笔初始计划风险2%，最多4只、单股≤30%、总股票仓位≤95%、同题材≤50%、总初始计划风险≤6%。约束在建仓时检查，市值漂移会改变实际比例。
- 初始止损取形态失效位与入场价−1.5 ATR中较低者；风险距离至少4%，超过10%跳过。股数向下取整数，不假定券商支持碎股订单。
- 仓位取风险预算、单股上限、组合/题材剩余额度、已结算现金中的最小值，买卖估算成本也纳入风险预算。单笔交易≤此前平均美元成交额0.1%。
- 例如某笔止损距离6%，按2%风险预算理论可用33.3%仓位，但单股30%上限使其计划价格损失约1.8%账户净值；费用另计。跳空下跌20%时，这一仓位的实际损失约6%，止损并不保证最多只亏1.8%。
- 日线研究版：收盘低于有效止损位，次一可执行开盘卖出；不以当天最低价伪造盘中止损。入场后3个交易日最高收盘浮盈不足0.5R，下一开盘退出。
- 收盘达到2R时，下一开盘卖出约1/3整数股，剩余仓位用最高收盘价−2 ATR跟踪；数量不足时一次平仓。R为入场时冻结的每股初始价格风险。
- 两周期限含入场日为第1个自然日；在第14个自然日及以前的最后一个已知交易日到期退出，并同时受10交易日上限约束。停牌、熔断或缺价时继续持仓并记超期，不能承诺实际两周内一定成交。
- 从账户净值高点回撤8%时，后续新仓风险预算减半；回撤15%时停止新开仓，既有风险退出继续。该次回放不自动恢复，需要另行明确重启规则。15%是动作阈值，不是最大回撤保证。
- 市场过滤只作预先声明的对照：QQQ收盘在MA50上方用上述额度，下方新仓风险预算减半、总仓上限50%。与无过滤版分别比较，不能看到后段收益才选择启用。

## 美股资金与执行适配

不借钱交易不等于券商账户类型一定是cash，实际权限应单独记录。首版保守使用已结算现金买入；卖出款按结算日释放。标准美股结算自2024-05-28为T+1，较早历史测试要按当时T+2等规则分段，不能全期倒填T+1。[SEC结算说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/new-t1-settlement-cycle-what-investors-need-know-investor-bulletin)

现金账户可以卖出用足额已结算资金买入的股票；使用未结算卖出款再买入，会涉及何时可以再次卖出的限制。本模型采用已结算资金约束，是便于即时风险退出的保守设计，不是声称法规禁止所有未结算款买入。[SEC现金账户说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/updated-9)

若实际是保证金账户，即使不借款，也应确认券商适用规则。FINRA新日内保证金标准自2026-06-04生效，券商过渡期可到2027-10-20；不能统一沿用“必须2.5万美元”，也不能假定每家已取消旧规则。[FINRA 26-10](https://www.finra.org/rules-guidance/notices/26-10)

需独立实现美股费用表、成交价差和滑点情景、美元结算账本、股息现金入账、拆股数量调整、退市处置、美国交易日历与纽约时区。港股的整手/印花税/港股通资格逻辑不能直接复用。

## 验证规格与当前状态

沿用现有持仓状态、重复信号不重置期限、截断一致性测试的设计，但美股模块尚未落地。下一轮实际回测应先冻结研究版本和数据清单，再取得包含退市的股票历史、日线、公司行为、财报事件、历史交易/结算日历。

分别测试A/B/C及市场过滤对照，先固定上述风险参数；仅对量比和5/8/10日持有期做小范围训练比较。按36个月训练、后6个月开发验证滚动，剔除训练截止时尚未结束的交易标签；分段账户起点和预热统一说明。所有反复查看过的历史均标为开发验证，真正前向样本从规则冻结后积累。

输出净收益、回撤、股票暴露、交易次数、盈亏比、单股/行业贡献、收益去掉前5大赢家后的变化，以及10/25/50bps单边滑点情景。以相同现金暴露对照和QQQ/SPY买入持有作不同用途的比较，不只看总收益最高者。模拟金额使用明确USD数额，不将原人民币预算按1:1当成美元。

本次交付为策略规格及规则核实；没有美股胜率、年化收益或回测成功的声明。
