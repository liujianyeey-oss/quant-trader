# 治理章程（GOVERNANCE）

> 唯一权威治理文件，2026-09-17 成文（backlog ⑪）。具体案例引用 `docs/LESSONS.md` 与各行业研究报告（R1~R9），本文件只定规则不复述案例。

## 一、晋升阶梯（任何策略/变更的必经路径）

1. **回测门**：预声明假设（见第六节模板）→ 训练段判效（卡玛改善 ≥0.1，过滤器类 ≥0.15 若为二元开关；且无最大回撤劣化）+ 验证段体检 + 高原/相位中位数口径（调仓周期 >1 日必须相位扰动）。
2. **模拟台账 ≥2~3 个月**：进入 paper*/paper_obs 观察账户前向跟踪；执行偏差（dev_bps 均值）不得超过滑点假设的 2 倍标准差。
3. **可跟单候选**：前两步全过，且在模拟期内滚动 252 日夏普不为负。
任何一步不达标即淘汰并记录原因；不允许跳级。"证据不足"是合法终点（样本量/历史覆盖不足时禁止硬选）。

## 二、换参决策规则（不可协商）

- 只按**训练段**排名决策；样本外（OOS）只做体检，永不作选参依据；污染段（已被开发看过的历史区间）永不作选参依据。
- 所有收益数字按**相位中位数**理解（LESSONS.md 相位运气案例）；锚定相位只作陈列。
- 排名看"高原"不选"孤峰"：邻域参数必须同向为正。
- 一个样本内外切分只消耗一次；看过 OOS 再改策略即消耗留出集，须重新声明新留出段。

## 三、季度 optimize 流程

- 每季度固定窗口重跑全网格（当前修正引擎口径），只允许在该窗口讨论参数变更。
- **相位极差为固定检查项**：任何变体的相位极差 >10pp 时其收益数字不可信，报告必须注明。
- 换参条件（预先成文）：新第一名与现配置的卡玛差 ≥0.1 且相位中位数也胜出，才进入评审；否则维持现状。
- 重跑结果存 `reports/optimize_results.csv` 并附相位分布。

## 四、紧急干预规则

- monitor **红牌**（滚动 252 日夏普 < -0.5）→ 48 小时内开评审会（可异步），评审结论书面化：维持/降仓/暂停。
- **禁止静默改参**：任何参数、池、成本、过滤器的变更必须先有研究文档和预声明，再走晋升阶梯；台账运行期间不允许"顺手调一下"。
- monitor **黄牌**（夏普 <0 或台账理论偏离 >2%）→ 下月体检重点复查，连续两月黄牌视同红牌。

## 五、候选变更条款

**511880 现金停泊**（docs/CASH_MANAGEMENT.md，预期 +0.2~0.7pp）：
1. 先以模拟台账验证 3 个月（现金腿改记 511880 净值，核对实操摩擦与模型一致）；
2. **停用条款：货币基金年化收益率 <1.2% 时自动停用停泊**（摩擦约 0.27%/年将吃掉收益）；
3. 实施位置优先在组合层现金桶（配合 R7a P2 组合），而非单策略内嵌。
