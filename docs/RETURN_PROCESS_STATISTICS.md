# 收益率过程统计刻画（T1）：我们标的的"数学个性"

日期：2026-09-17。方法：日收益 ACF、Lo-MacKinlay 方差比 VR(q)、DFA Hurst 指数；分段 2019-2023 / 2024+。数据：`research_stats/results/return_process.csv`。解读约定：VR>1/Hurst>0.5 趋势性；VR<1/Hurst<0.5 均值回归；VR 的 z>1.96 为 5% 显著。

## 关键结果

| 标的 | 统计个性 | 显著性证据 |
|---|---|---|
| **588000 科创50** | **最强趋势性**（且 2024+ 进一步增强） | VR5=1.138（**z=2.37 显著**）、Hurst 0.584→0.637、ACF1 +0.105~0.136 |
| 510500 / 159915 / 510300 | 温和趋势性 | Hurst 0.52~0.62；ACF20 +0.02~0.06（与 20 日动量窗口匹配） |
| **518880 黄金** | **显著的短周期均值回归** | VR10=0.835~0.846（**z=-2.14~-2.37 显著**）、ACF2 -0.068~-0.106、Hurst≈0.50 |
| **QQQ / SPY** | 日频~月频均显著回归 | ACF1 **-0.12~-0.16**、VR5=0.815（**z=-4.18 显著**）、Hurst≈0.50 |
| **BTC** | **3 个月尺度的显著趋势** | VR63=1.310（**z=1.97 显著**）、Hurst 0.55~0.56 |

## 三句话结论（客观规律，非回测拟合）

1. **我们 A股动量轮动的数学基础被证实**：宽基池里 588000/510500/159915 都有正自相关结构，且 2024 后普遍增强——动量轮动的持续有效性有统计根据，不是参数侥幸。
2. **黄金 ETF 的短周期均值回归是显著的客观规律**——它当防守资产"顺便正确"：趋势走坏时躲进一个均值回归资产，等于在防守期叠加了一层回归 buff。
3. **美股唐奇安的有效不来自趋势**（QQQ/SPY 所有尺度都在回归）——它赚的是**截断左尾的期权式不对称收益**，不是趋势延续。这解释了为什么它对参数高原不敏感。

## 由统计结构推导的候选算法（预声明后再测）

- **gold-MR 增强**：518880 在连续 2 日下跌且 20 日动量为正时加 10% 仓位（防守期内部署 MR 以增强防守收益）——统计依据 z=-2.4
- **BTC 63 日动量 / 长窗唐奇安**（40/20 或 63/21）：BTC 的显著趋势在 3 个月尺度而非 20 日尺度——消耗更少交易、捕捉更长的趋势
- **588000 趋势增强**：它是全池最强趋势标的——入池依据从"配置直觉"升级为"统计支持"
