# hk_swing：两周内港股短线算法与回测

已接入 `main.py` 的 backtest、signal、optimize。独立配置为 `hk_swing`，不改动 `hk_connect` 中期策略、A 股策略或既有模拟盘。模型只研究现金做多，不发券商订单。

## 运行

```bash
cd /Users/liujianye10/quant-trader
source .venv/bin/activate

# 固定基线回测，默认 50 万 HKD、2025-07-01 至 2026-09-08
python main.py backtest --strategy hk_swing --research --offline

# 18 组预设参数，仅训练段选参；输出后段开发验证、资金/滑点及星期敏感度
python main.py optimize --strategy hk_swing --research --offline

# 模型账户重放后的状态及最近收盘候选，不代表实际券商持仓
python main.py signal --strategy hk_swing --research --offline

# 指定资金，或采用某次研究输出的参数（替换为真实生成的目录）
python main.py backtest --strategy hk_swing --research --offline --capital-hkd 1000000
python main.py backtest --strategy hk_swing --research --offline --params reports/hk_swing_时间戳/selected_params.json
```

首次没有缓存时去掉 `--offline` 顺序拉取，默认 26 只观察股票及 02800 基准。缺股票行情、预热不足或缺基准日期直接报错，不删除失败样本。`end` 是冻结研究截止日，查看更新行情应明确传 `--end YYYY-MM-DD` 并确保源数据确实覆盖；输出始终显示真实行情范围。

账户单位 **HKD**；10 万人民币不是 10 万 HKD。`--capital-hkd` 是独立投机子账户的研究金额，不自动换汇，也不与 A 股账户合并。

## 算法口径

### 共用筛选

- 对应通道资格在实际入场日再次核验；当前自动名单只覆盖 SH 通道。
- 至少 60 根历史日线，平均 20 日 `close × volume` ≥1 亿 HKD，原始股价≥3 HKD。
- ATR 为过去 14 日真实波幅的简单均值；ATR/close 在 3%–8%。
- 使用真实未复权 OHLC 定义技术形态，不从复权收盘价伪造复权高低价。复权因子变化超过 3% 后至少 30 根/形态窗口内不入场；持仓期因子跳变超过 10% 则报错，要求补公司行为数据，不能伪造拆股收益。
- 信号排序为 20 日价格涨幅除以 ATR/close，同分按代码顺序。不再采用原先 60/120 日轮动。

`close × volume` 是流动性近似值，未调整的除息价格变化也会影响形态；这些是已知研究限制。

### breakout

收盘突破截至昨日的过去 20 日最高价，量比≥1.8（量能基准窗口不含当天）；收盘位置处于当日振幅的上方 25%，收盘偏离原突破位不超过 1 ATR。

### pullback

回撤开始前 10 日涨幅≥10%；此前 3 日缩量，距前期高点回撤 0.5–1.5 ATR；当前收盘重新越过昨日高点且高于 MA20，同时量能恢复到回撤均量的指定倍数。与 breakout 分开记录，不能把没有成交的参数称为低风险赚钱策略。

### 事件标签

默认 `require_catalyst: false`，实际测试的是**纯量价对照**。设置为 true 时必须配置 `events_csv`，列为：

```text
code,published_at,approved,source
```

code 为五位代码，approved 只能为 0/1，source 保留原始公告来源。无时区时间按香港时间解释；只有信号日 16:10 前、过去 5 个自然日内已经发布且通过审核的标签才可用。18:00 公布的公告不能用于同一天收盘信号。标签本身仍须人工保证是当时可知的信息，无法由文件格式证明无事后偏差。

### 入场和仓位

上一行情日收盘信号在下一通道开放日、且该股票有原始开盘价时才可能成交。高开上限为信号收盘价上方 `min(3%,0.5 ATR/close)`，低于触发位也不买。

初始失效位取形态失效位下方 0.5 ATR 和入场价下方 1.5 ATR 中较低值；计划风险距离至少 4%，超过 10% 放弃。费用及退出滑点纳入计划风险取整计算：

`n × (入场成交价 − 失效位 × (1−滑点)) + 买卖估算费用 ≤ 净值 × 2%`

同时满足：最多 3 只、单股≤35%、股票总仓位≤90%、单题材≤45%、所有持仓原始计划风险之和≤6%、单笔金额≤此前日均成交额的0.2%。现金及各股票手数再次限制股数，无法买一手就不成交。市场跳空可能突破计划损失；这些上限是建仓约束，持仓漂移会改变实际比例。

### 持仓状态与退出

每笔持仓保留首次成交日、原始入场成本、股数、初始风险距离、含费用计划风险、到期日、最高收盘价、是否已减仓、待执行退出和是否超期。

1. **收盘止损**：收盘跌破当时有效失效位，下一可执行开盘卖出；跳空损失按实际开盘承受。当天最低价触碰不代表本模型已经止损。
2. **时间止损**：入场日计为第1日，满3个持有日且最高收盘浮盈未达0.5R，次一可执行开盘退出。
3. **盈利减仓**：收盘达到2R，次一开盘卖出约半数整手；不足两手则全卖。剩余仓位以截至收盘的最高收盘价减2ATR跟踪，下一时点生效。
4. **到期**：默认含入场日第8个计划通道日收盘退出，参数上限10日，并受14个自然日期限约束（入场日为第1个自然日，避免收盘退出超过入场后14×24小时）。已知长期通道假期提前退出；加仓或重复信号不重置计时。本版本不在已有持仓上重复开新仓。
5. **执行失败**：股票停牌/缺价时保留持仓、继续按最后价格估值并重试，超过计划退出日记录 `deadline_breach`。其他股票可独立退出。
6. **账户暂停**：净值从高点回撤达到10%后，本次模拟剩余区间停止新开仓，已有退出继续执行；不会因为后来反弹自动解除。若实务上复核后重启，应另建明确起点的研究账户，不可事后抹掉暂停期。

日线版本不假定盘中买入、盘中止损或先触及止盈。只有预定期限的退出采用当日收盘价减滑点的假设，仍不等于竞价限价委托一定成交。未平仓不会因回测结束而假平仓；完整回合统计不含仍持有仓位，但账户净值包含它们。

## 优化过程

研究区间默认 2025-07-01 至 2026-09-08。训练期截至 2026-01-31，分为 2025-07 至10月、2025-11 至2026-01 两段，各从相同初始资金重放；后段从2026-02开始单独检查。完整区间另连续回放一次，不能把独立重置账户的分段收益直接相乘当成完整结果。

18 个候选：breakout 的回看10/20日×量比1.5/1.8×最长5/8/10日共12组；pullback 固定形态定义×量比1.5/1.8×最长5/8/10日共6组。其余风险参数预先固定，不按后段收益改写。

训练评分为两段平均 `累计收益 + 1.5 × 最大回撤（负数）`；最终排序评分各取自身得分与同类相邻参数组中位数的一半。每段至少3个完整回合、合计至少10个才进入候选比较，这只是避免无交易策略占据榜首，远非统计充分性保证。

训练引擎只接收 train_end 及以前的行情；锁定参数后才运行后段、完整区间、10/50/100万 HKD × 10/20/30bps 单边滑点的9组压力测试，以及5个信号星期的分组审计。星期审计不用于挑一个赢家替代每日扫描。

所有开发结果已暴露，因此后段只是开发验证。当前股票/手数回填、26只人为观察池和缺真实通道日历的偏差仍在；本轮结果不能成为独立样本外证据。`selected_params.json` 不会覆盖默认参数，也不会自动交易。

## 产物与复核

每次运行在 `reports/hk_swing_时间戳/` 保存来源快照及数据哈希；优化另保存训练候选排名、选定参数、前后段及完整对比、资金滑点情景、星期审计、按股票利润贡献、研究评估和净值图。各场景子目录包含净值、逐笔买卖、完整回合、延期异常、期末持仓及技术候选。

基准为02800原始开盘起算的价格收益，不含分红和交易费用；它采用100%股票暴露，不能直接以它和低仓位策略的差值宣称纯选股超额收益。报告始终另列策略平均仓位。

验证命令：`python -m unittest discover -s tests`。短线专项覆盖因果性、收盘止损隔夜跳空、单根日线最低价不虚构止损、最大期限、假期提前退出、停牌超期、未平仓估值、整手减仓、事件时间戳、回撤暂停、题材/风险限制、回撤策略正例和停牌后复权跳变拒绝。
