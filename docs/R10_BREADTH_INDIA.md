**核心结论：① 宽度过滤正中 R8-H3"内生已覆盖"死法——宽度触发日与 MA60 趋势防守日的重合度 83.3%（>80% 预声明线），且训练卡玛 0.68 vs 基准 0.94、全期 0.45 vs 0.65，判定证伪（R7b 交易行业是负 alpha，本研究把行业当状态信息依然无增量）。② 印度 164824 不改变 R1 结论：相关性 0.24 分散价值真实，但入池后相位中位卡玛全面持平或略降，且近 20 日日均成交额仅约 16 万元（近似）——即使指标好看也会死于流动性，维持 R1 不扩池决议。**

## ① 市场宽度指标

定义：9 只行业 ETF（R7b 池）收盘价 > 各自 MA60 的比例（未上市剔除归一化）。序列统计：全期最低 0、最高 1，<30% 的天数占 32.1%。规则：调仓日宽度 < 30% → 该周期进防守。

### 冗余自查（预声明：重合度 >80% 判"内生已覆盖"）

| 指标 | 数值 |
|---|---|
| 调仓信号日数（相位0） | 468 |
| 宽度触发日数（<30%） | 150（32.1%） |
| MA60 趋势防守日数 | 180 |
| 两者重合日数 | 125 |
| **宽度触发中趋势也防守占比** | **83.3%** ⚠️ 超 80% 预声明线 |
| 趋势防守中宽度也触发占比 | 69.4% |

解读：宽度触发几乎是 MA60 趋势过滤的子集——市场层面的宽度与标的层面的趋势过滤度量的是同一风险（行业普跌时宽基也必破 MA60）。剩余 17% 的"宽度独有"触发没有提供新信息，只增加误动作。

| 指标 | 数值 |
