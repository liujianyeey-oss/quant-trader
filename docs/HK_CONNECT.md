# 港股通股票模块

`hk_connect` 是独立的港币股票研究策略，已接入现有 `signal` / `backtest` CLI。参数是预先设定的起步规则，未经收益寻优，尚无独立样本外有效性证据。A 股 ETF 策略和 `paper-update` 继续使用原有账户。

## 运行

```bash
cd /Users/liujianye10/quant-trader
source .venv/bin/activate

python main.py hk-universe
python main.py signal --strategy hk_connect

# 本地已缓存时，不联网复用；旧数据会显示日期，过期则拒绝当前信号
python main.py signal --strategy hk_connect --offline

# 当前名单回看历史，仅为探索；不能据此声称历史上可执行
python main.py backtest --strategy hk_connect --research --start 2025-07-01 --offline
```

首次 `signal` 会自行更新名单，不必先单独运行 `hk-universe`。默认顺序加载 16 只观察池股票，缓存独立存放于 `data_cache/hk_connect/`。不会向券商发送订单，也没有新增定时任务或自动加入模拟盘。

信号保存在 `signals/YYYY-MM-DD_hk_connect.txt`。回测在 `reports/hk_connect_时间戳/` 保存 `equity_hkd.csv`、`trades_hkd.csv`、`targets.csv`、`summary.json`；后者包含配置、完整资格快照、数据日期、费用、延期次数和限制，便于复核。目标是模型仓位，不是已有持仓；参考股数按空仓账户计算。

## 股票范围与规则

第一版自动抓取**沪港通南向可买名单（SH 通道）**，再与 HKEX 证券表交叉检查 `Equity`、`HKD`、每手股数和印花税标志。它是港股通股票的合法研究子集，**不包括只在深港通可买的股票**。沪、深名单不能互相替代。每次抓取保留观察日期和官方来源，绝不把列表更新日期解释为个股最初纳入日期。

`hk_connect.watchlist` 是起步观察范围，不是买入推荐或按历史最优选择的股票。默认 16 只；设为 `[]` 才会逐只加载当前完整 SH 股票名单。缺行情直接报错，不以删除失败股票的方式改变样本。观察池股票从可买名单退出后不再产生新买入目标。

| 环节 | 默认规则 |
|---|---|
| 数据 | 仅使用香港当日前的完整日线；当天收盘后仍待次日才使用当天数据 |
| 流动性 | 最近 20 个港股行情日，平均收盘价 × 成交股数 ≥ 5,000 万 HKD；这是成交额近似值 |
| 价格 | 原始收盘价 ≥ 3 HKD |
| 趋势 | 复权收盘价高于 120 日均线；60 日和 120 日涨幅都大于 0 |
| 排序 | 60 日涨幅与 120 日涨幅各占 50%，取最多 5 只；同分按代码确定顺序 |
| 仓位 | 60 日波动率倒数分配；单只目标 ≤ 20%，组合目标 ≤ 80%，剩余现金 |
| 可负担性 | 用配置的研究预算和信号日真实价格检查整手成本，剔除无法按目标买一手的股票，并依次补入下一名；周度建仓至少 3 只 |
| 风险预算 | 加权单股年化波动之和 ≤ 12%，不采用相关性带来的分散化折扣 |
| 调仓 | 周三或之后本周首个有行情的交易日收盘计算；下一可交易日开盘假设执行 |
| 日常退出 | 跌破趋势、缺失当日行情或失去资格时，目标归零；不在周中重新开仓 |

12% 是**建仓时的波动预算**，不是最大回撤保证；持仓漂移、跳空、相关性和停牌会改变实际风险。无信号时可以全部持有现金，没有强行指定防守股票。周度日历锚定避免数据起点变化导致整个调仓相位移动，但不同星期的收益仍应检查。

可负担性筛选使用 `initial_cash_hkd` 作为固定研究预算，避免从回测未来净值倒推选股；实际成交仍按当日账户净值和开盘价格计算，净值变化或跳空可能影响成交手数。日常风险退出可能使剩余持仓少于 3 只，此时保留合格剩余仓位，不为凑数新买股票。修改账户研究预算会影响可选组合，因此不同资金量应单独验证。

策略使用同一份目标序列产生信号和回测；当天数据只能产生次日成交目标。未复权开盘价用于估值、取整和成交；复权收盘价只用于趋势/动量。原始和复权接口共同日期范围外的数据会裁去，共同范围内部缺行会报错。腾讯成功的 qfq 请求对无调整序列可能返回 `day` 键，只有与独立原始 OHLC 逐日一致才接受，并保留来源元数据。

## 十万至百万账户怎样使用

`initial_cash_hkd` 默认 **100,000 HKD**，可改为实际分配给策略的港币等值研究预算。它不是人民币总资产，不会自动换汇；`backtest.initial_cash` 仍只属于 A 股账户。每只股票的每手股数从官方表获取，不统一假设 100 股；预算买不起一手时保留现金，不突破单股目标补买一手。

对于已有港股通权限的账户，可先将它作为独立的观察/模拟组合。100 万人民币级账户也应按实际分配金额配置，不能直接把策略账户当成全账户风险预算。与 A 股 ETF 同时持有时，金融、科技、能源等风险会重叠，本模块尚无跨策略或行业仓位上限。

若尚未开通权限，10 万人民币的总资产通常不足以满足开户资产条件：上交所一件事平台说明，个人申请前 20 个交易日日均资产不低于 50 万人民币，融资融券融入资产不计入。**策略分配资金少于 50 万**与**账户是否满足开通条件**是两回事。[上交所开户条件](https://one.sse.com.cn/onething/gptz/)

## 成交、费用与收益口径

模型先卖后买，整手交易，买卖两边收取佣金及交易税费。印花税向上取整至 1 HKD，其余列示交易征费按分四舍五入。最低佣金和费用不能导致现金透支。持仓或目标股票缺开盘价、零成交量，或显式通道日历关闭时，整次调仓延期；完成目标仅在成交过程执行后更新。**一只停牌股票可能拖延整个组合**，报告中的 `pending` / `deferred_days` 可检查该保守假设。

配置的佣金万三、最低 5 HKD 是研究假设，并非券商统一标准。印花税 0.1%、交易费 0.00565%、SFC 征费 0.0027%、AFRC 征费 0.00015%，按双边收费建模。[HKEX 交易费用](https://www.hkex.com.hk/Services/Rules-and-Forms-and-Fees/Fees/Securities-%28Hong-Kong%29/Trading/Transaction?sc_lang=en)

结算费采用 HKSCC 现行 0.0042% 的传导情景；南向投资者实际费用的转嫁、额外收费和最低佣金币种必须按券商账单校准，不能把此处费率当成完整港股通收费承诺。[HKEX 结算费用](https://www.hkex.com.hk/Services/Rules-and-Forms-and-Fees/Fees/Securities-%28Hong-Kong%29/Clearing-and-Settlement/Operational?sc_lang=en)

所有回测时期统一使用配置的当前费用，尚未重建各时期税率。`extra_fee` 可用于额外按成交额收费的压力情景，滑点默认单边 10 bps。开盘加滑点仅是假设价格，并非符合港交所价格档位的真实委托；没有逐笔撮合、冲击成本、资金冻结、T+2 结算现金或临时通道限制。

**回测输出是 HKD 价格收益，未计分红和人民币汇率收益。** 没有现金分红、红利税、换汇价差、持有服务费和利息；高分红股票的价格收益尤其不能当成完整投资收益。港股通实际结算涉及人民币及结算汇率，参考汇率也不等于最终结算汇率。[上交所汇率说明](https://edu.sse.com.cn/service/hotline/qa/c/5717491.shtml)

暂不支持拆并股、送股、配股和碎股处置。实际回测窗口中复权因子变化超过 10% 时会拒绝运行，要求补齐公司行为模型；较小变化也可能是公司行为，检测不是完整核验。默认研究起点 2025-07-01 同时避开观察池此前已知的大型拆股事件和结算费切换边界，不是按收益挑选的最优起点。

## 历史资格、日历与长历史

自动下载的 `snapshot` 只有观察日，不是历史成分数据。因此当前名单回测必须显式添加 `--research`，并始终标记幸存者偏差、当前手数回填以及观察池选择偏差。缺少通道日历时，探索模式以港股有行情日近似；这可能在港股通关闭的日期模拟成交。信号命令不猜具体执行日，委托前需以通道和券商状态为准。[官方港股通资格入口](https://www.hkex.com.hk/Mutual-Market/Stock-Connect/Eligible-Stocks/View-All-Eligible-Securities?sc_lang=en)、[SH 南向名单](https://www.sse.com.cn/services/hkexsc/disclo/eligible/)

可以将 `universe_file` 指向自备的完整历史记录，例如以下**格式样例（日期并非真实纳入记录）**：

```json
{
  "mode": "intervals",
  "observed_at": "2026-09-09",
  "route": "SH",
  "securities": [
    {"code": "00700", "name": "格式样例", "category": "Equity", "currency": "HKD",
     "lot": 100, "stamp_duty": true, "buy_allowed": true,
     "valid_from": "2025-01-01", "valid_to": "2025-06-30"},
    {"code": "00700", "name": "格式样例", "category": "Equity", "currency": "HKD",
     "lot": 100, "stamp_duty": true, "buy_allowed": false,
     "valid_from": "2025-07-01", "valid_to": "2026-12-31"}
  ]
}
```

区间含首尾且不允许重叠；完整记录应涵盖历史退出/退市股票、手数及资格变化。没有适用区间时禁止新买，已有持仓退出时沿用最后已知手数。`buy_allowed=false` 表示仅允许退出，不代表股票停牌。数据提供者仍需保证每条记录当时已经可知、通道匹配且覆盖完整，本模块不能凭 JSON 格式验证这些事实。

`calendar_csv` 指向该通道的 `date,is_open` 文件，`is_open` 必须为 `0` 或 `1`；需要覆盖回测窗口中的**每个港股行情日**，不能只列开通日期。历史区间和日历都提供后可不加 `--research`，但公司行为、人民币现金和历史费用缺口仍然存在，不能因此将回测称为实盘复刻。

腾讯单次返回最多约 640 根日线。程序不把短历史伪装成长回测；若起点前预热不足会报错。长历史可导入 `cache_dir/五位代码.parquet` 并用 `--offline`，必需列为：

```text
date,open,high,low,close,volume,signal_close
```

OHLC 为未复权 HKD 价格，`volume` 单位为股，`signal_close` 为一致口径的复权收盘价；停牌无行情日用缺行表示，不要用未来收盘价回填成交价。成交额近似值由原始 `close * volume` 重算。

## 验证

运行 `python -m unittest discover -s tests`。港股专项回归覆盖未来数据不改变已有信号、当日收盘不影响开盘股数、资格到期、可买/仅卖区间、不同手数、费用取整、现金不足、通道关闭、停牌延期、缓存中的未完成日线、原始/复权对齐和大幅公司行为拒绝。

下一阶段应冻结观察池和参数后前向记录信号；比较不同调仓星期、单边滑点 10/20/30 bps 和不同资金量。补齐历史资格、公司行为、分红及真实结算费用后，才适合评价完整收益，并决定是否接入独立港股通模拟盘。
