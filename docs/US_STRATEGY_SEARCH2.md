## 六、新假设探索（explore）

**6. regime 自适应（ADX>25 且 +DI>-DI 用唐奇安，否则 RSI2 均值回归）——淘汰。**
QQQ 训练 -1.2%/-14.1%（卡玛 -0.08）、SPY 训练 0.2%/-11.2%（0.01）；验证段虽 3.00/1.56，但训练段已被判死：2020-2022 震荡市反复触发模式切换，每次切换强制平仓都白付一轮成本（换手翻倍到 ~20x/年）。自适应切换在该池该段是负贡献，不保留。

**7. 多均线投票仓位（站上 MA20/50/100/200 比例即仓位）——淘汰。**
QQQ 版训练 0.47、全期 12.8%/0.68，全面略低于唐奇安基准（0.73/0.83）；SPY 版 0.22/0.36 明显更弱。回撤控制也没有更好（-18.8% vs -16.0%）。不改善，不保留。

**8. 防守品种独立唐奇安 sleeve——信号弱、组合有相关亮点，保留为观察假设。**
GLD/TLT 独立 20/10 唐奇安本身失败（训练卡玛 0.08/0.03，见泛化表），不能作为独立 sleeve 的信号。但 50/50 组合仍有信息价值：

| 组合 | 全期 年化/回撤/夏普/卡玛 | 与 don_QQQ 日收益相关 |
|---|---|---|
| don_QQQ 单持 | 13.3% / -16.0% / 1.03 / 0.83 | 1.00 |
| 50/50 QQQ+GLD | 8.9% / **-13.3%** / 0.94 / 0.67 | GLD 腿仅 0.03 |
| 50/50 QQQ+TLT | 5.1% / -12.0% / 0.66 / 0.42 | TLT 腿 -0.02 |

组合降低了回撤（-16.0%→-13.3%）但卡玛变差——sleeve 腿的低收益拖累了整体。与上轮"组合救不了弱成分"一致。**保留为观察假设**：若未来用真实强势防守资产（而非唐奇安信号的 GLD/TLT 腿）构建组合，接近零的相关性仍值钱；当前形态不推荐。

## 七、最终推荐（无变化）

1. **donchian_QQQ 20/10**（主）：高原测试确认参数稳健（邻域训练全正、验证 ≥1.38）；50bps 成本下仍存活；全期 13.3%/-16.0%/夏普 1.03。
2. **donchian_SPY 20/10**（防守伴侣）：训练/验证/全期一致（0.93/1.41/0.95），回撤 -9.2%。
3. 备选记录（不构成推荐变更）：SPY 侧 Chandelier 3×ATR22 退出与 low10 同高原；XLK 与 QQQ 同族冗余、不必单列。
4. 明确边界：策略只在 QQQ/SPY(/XLK) 上有效；MDY/IWM/GLD/TLT/EFA 上勿用；全期绝对收益仍低于 QQQ 持有，定位仍是"回撤约束资金的防守型趋势策略"。
