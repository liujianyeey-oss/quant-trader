# 港股通两周短线：实现与回测结果

完成日期：2026-09-10。已实现 `hk_swing` 独立策略，完成 18 组参数比较及资金、滑点、触发星期检查。**本轮没有找到符合“高回报”目标的可靠策略；不能将开发回测包装为已经验证的盈利方案。**

## 结论

主模型为“放量突破”，训练期选出的参数仍是基线：20 日突破、1.8 倍量、最多 8 个计划交易日。优化没有提高收益，默认参数也未被优化程序自动改写。

50 万 HKD 账户，全期累计收益 **3.67%**，最大回撤 **-5.96%**，21 个完整交易回合；后段开发验证 **-3.63%**。较早的 3.37% 是另一套中期模型的结果，不能将不同规则及区间的数字直接解释为改进幅度。

实际行情区间 **2025-07-02—2026-09-08**，这是约 14 个月的累计收益，不是年化收益。起始配置为 2025-07-01，实际首根行情在 07-02。按当前 26 只 SH 通道观察股票回填历史，包含选择偏差；不是全港股通扫描。

## 策略到底执行什么

- 股票先满足价格≥3 HKD、20 日平均成交额近似值≥1 亿 HKD、ATR/价格在3%–8%。
- 突破模型：收盘超过昨日以前20日最高价，量比≥1.8，收盘位于当日振幅上方25%，偏离突破位≤1 ATR。
- 回撤模型：强势上涨后缩量回撤0.5–1.5 ATR，放量重新站上昨日高点和MA20；与突破模型分别评估。
- 当天收盘确认，次一可执行开盘入场；高开超过3%或0.5 ATR对应幅度则不追，跌回触发位以下也不买。原始OHLC与整手交易用于成交。
- 每笔初始计划损失预算2%，最多3只，单股35%、总仓位90%、题材45%、总计划风险6%；跳空可使实际损失超过预算。
- 收盘确认止损后次一可执行开盘退出；3日未达到0.5R按停滞退出；2R次一开盘减约一半整手，其余跟踪2 ATR。
- 默认第8个计划交易日到期，参数不能超过10个计划交易日；入场日算第1个自然日，总期限≤14个自然日。停牌导致无法退出时记录延期，不编造成交。
- 账户回撤10%暂停新增，已有退出继续。无券商下单、无自动启用或既有模拟盘改动。

当前没有完整历史催化标签，因此实测是**纯量价策略**。已有可选事件时间戳接口，但它并不等于业绩/公告催化策略已经回测成功。

## 为什么收益仍然低

50万账户平均股票仓位只有 **7.15%**，并非一直以90%仓位运行；流动性、波动率、突破形态、隔夜跳空与仓位限制共同压缩了机会。仅设置高仓位上限不会自动产生足够交易。

全期净利润约 **18,352.73 HKD**，其中01347贡献约27,883.49 HKD，超过组合总利润；多只股票抵消了收益。赢家集中且完整回合仅21次，缺少稳定性证据。50万账户胜率42.86%、盈利因子1.31；这些都是小样本描述。

回撤模型全期仅1个完整回合、累计收益 **0.52%**；其训练候选没有足够交易，未获得选参资格。不能把这一笔盈利称为100%胜率策略。

50万账户全期手续费约7,710.95 HKD，平均持仓自然日差约6日，最长自然日差11日、最长含入场日8个交易日；本样本无超期记录、期末无未平仓。日期差不包含日内成交时刻，停牌时算法无法保证现实中两周内成交退出。

基准02800同期价格收益 **4.44%**，按100%股票暴露、不含分红和交易费用计算；策略平均仓位很低，不能仅用两者差值断言选股能力。

## 优化与验证口径

训练期为2025-07至2026-01，分为7—10月和11—1月两段独立账户；每段至少3个完整回合、两段合计至少10个才可选。12组突破参数和6组回撤参数只看训练期。评分兼顾收益、回撤及同类参数组中位数。选中参数的训练邻域评分仍为负，缺乏稳定的参数区域。

锁定后检查2026-02至09-08：收益 **-3.63%**、最大回撤 **-6.18%**，8个完整回合。后段已被查看，且模型设计受既有历史研究影响，所以标为“开发验证”，不能声称独立样本外。

另外检查5个信号星期与9个资金/滑点场景，不根据这些结果挑一个表现最好的星期重新包装策略。分段账户独立重置，分段复利不必等于连续全期回测。

## 数据和执行限制

1. 当前资格与当前每手股数回填历史；26只股票也由观察池选择，存在幸存者和选样偏差。
2. 尚无完整逐日港股通开放日历，按工作日规划、按港股有行情日执行，可能含通道不开放的成交假设。
3. 未计分红、红利税、人民币汇率、换汇价差及持有费用；原始价格会受除息影响。大幅复权因子跳变的持仓会拒绝计算，等待公司行为数据。
4. 日线不能证明盘中止损成交；本版明确采用收盘确认/下一开盘。预定到期按收盘减滑点也是假设，真实竞价可能不成交。
5. 1亿成交额阈值使用收盘价×成交量近似，成交量原始数据质量及小样本限制仍需后续前向验证。

因此，**本轮实现可作为研究框架使用，尚不支持提高资金暴露投入实盘。** 更有价值的下一阶段是补齐当时可交易股票与通道日历、构建带真实发布时间的公告事件样本，在更广观察池上固定规则做前向验证。直接放大仓位会同时放大已有失效交易，不能解决信号优势不足。
