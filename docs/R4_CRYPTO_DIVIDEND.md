2026-09-17 完成，RESEARCH_PLAN R4 阶段。基准：BTC/ETH 唐奇安 20/10（t 收盘→t+1 开盘，taker 10bps+滑点 10bps，365 日历，复用 macro_research 实现与币安镜像数据层）。训练 ≤2022-12-30 判效（卡玛改善 ≥0.1），验证 2023-2024 体检，2025+ 只报告。

过滤器触发统计（如实交代"为什么无效/有效"）：

- **F3 费率拥挤**：BTC 拥挤日占 1.9%（62 天）、ETH 2.9%（96 天），但**没有任何一天与空仓状态下的突破入场日重合**——过滤器零实际操作，结果与基准逐位一致。预声明阈值（max(120 日均值+1σ, 0.05%/8h)）在 2020-2022 样本上过宽。"聪明钱"费率信号在本实现下没有产生任何决策，不是"被证伪"而是"未触发"——若未来重测需预先声明更严阈值并重新走训练/验证流程。
- **F1 量能确认**：BTC 训练段空仓状态下 6 次入场因量能不能足被跳过（17→11 笔），跳过避开的正是 2021-2022 几次缩量假突破（回撤 -54.5%→-37.4%）；验证段同样改善（1.85→3.19）。**但样本仅 11~17 笔**，且 ETH 同规则训练段变差（1.85→1.46）——跨资产不一致说明它可能是 BTC 特有的微观结构（币安 BTC 真突破放量、假突破缩量）而非普适规律。
- 与 R1/R2 量过滤死法对照：R1"缩量上涨跳过冠军"（A股动量）与 R2"地量见底"（永不触发）已归档；F1 是"突破放量确认"（crypto 突破），三者方向不同，本轮 F1-BTC 是量过滤家族里首个存活案例——**恰恰因为它与原死法不同构**（趋势突破入场确认 vs 动量排名惩罚/反转入场条件）。
