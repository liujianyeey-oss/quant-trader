# 美股现金短线实现与实验口径

`us_swing` 是独立的 USD 研究模块，现金做多、无借款、最长10个交易日且受两周自然日期限约束。代码在 `us_equities/`，研究配置在 `us_equities/config.json`。不接券商，不更新现有模拟盘。

## 执行

```bash
cd /Users/liujianye10/quant-trader
source .venv/bin/activate
python main.py backtest --strategy us_swing --research --offline
python main.py optimize --strategy us_swing --research --offline
python main.py backtest --strategy us_swing --research --offline --capital-usd 15000
python main.py signal --strategy us_swing --research --offline
python -m unittest discover -s tests
```

首次获取行情去掉 `--offline`。已存在的缓存不会被自动刷新；截止日期缺失或过旧会拒绝测试，更新缓存需要明确取得新数据。`--params` 接受参数JSON或优化生成的 `selected_params.json`。`--start/--end` 可用于单次回测；优化采用固定训练边界。金额是美元，不能把人民币预算直接按同数额美元回测。信号入口展示从指定起点重放出的模型状态，不代表券商真实持仓。

## 本轮股票和数据

股票池在读取策略收益前锁定为118只跨11类行业的观察股票；另外加载QQQ和SPY仅作基准。它仍是当前存续股票池，且包含人工选样偏差，不能宣称已经消除幸存者偏差。新上市股票要积累120根日线才进入信号。数据失败或截至期过旧不能静默删股票。

Yahoo在当前网络不可用，采用新浪未复权日线与其前复权因子中的乘法部分。实际成交价、价格门槛、现金和股数都使用当时单位；技术指标以同一拆股单位计算，再转换回信号日真实美元价格。只使用乘法因子调整拆股，不使用加法分红因子，因此收益明确不含分红现金。现有来源的公司行为未经全量独立核对，拆并股股数从供应商因子变化推导；产生的零碎股权益随最终出售估算处置，不模拟券商实际现金替代日期。

缓存新下载数据固定截自2017年，研究起点支持2019年及以后，为初始指标保留充分预热。QCOM/MCHP/INTU曾在2008—2012年的源数据出现OHLC关系错误，均在研究与预热区间之外；没有根据收益决定删行。供应商OHLC矛盾行原样记入隔离清单，不修造价格，不参与成交；此后60个自然日禁止该股新信号，持仓缺价保留估值/待退出。单股超过5个此类错误则拒绝加载。非正价格、无效因子和重复日期仍报错。隔离会带来执行与覆盖偏差，必须与回测一起披露。

交易日历为 `exchange-calendars` 的XNYS。交易日历近似用作现金结算日历，某些银行假日或券商行为差异未覆盖。因子只有当日生效以后才调整持仓；拆股日取消沿用上一日价格单位的新买单。

## 与研究设想的差异

本轮实测四类技术信号：

- breakout：20日涨幅在当时满足价格、流动性、波动及上市日数条件的股票前10%；收盘突破前20日最高价，放量且收在当日振幅上方25%，离突破位不超过1 ATR。
- pullback：回撤前10日涨幅≥10%，三日缩量回撤0.5—1.5 ATR，再放量收回前日最高价及MA20。**这是三日回撤代理，并未证明是某次突破后的首次回撤。**
- rotation：10或20日相对强度在合格股票池前10%，股价在MA20上方、5日和动量窗口涨幅为正，每日扫描且沿用固定持仓期限；不要求稀有放量事件。
- gap：开盘较前收盘涨4%—15%，放量，收盘不低于开盘且处于当日振幅上方25%。**没有可靠财报事件标签，不称为财报策略。**

未实现“未来已知财报前退出”的事件规避，因为缺少逐时点财报预告日历。所有指标只依赖已完成日线；量能均值的基准窗口不含信号日。股票价格≥10 USD，20日平均收盘价×成交量≥5,000万美元，ATR/价格为3%—8%。

## 成交、资金与风险

- 下一交易日开盘才可能买入，不跌破信号触发位，向上偏离信号收盘不超过min(3%,0.5 ATR/收盘)。跳空代理的向下容忍为0.5 ATR。
- 单笔计划风险2%、最多4只、单股30%、总仓95%、同类行业50%、总初始风险6%，单笔金额≤此前平均成交额0.1%。风险预算纳入估算双边成本和退出滑点，建仓股数为整数。
- 初始止损距离至少4%；取形态失效位及1.5 ATR中更远的失效距离，超过10%就跳过。
- 收盘跌破止损后下一可执行开盘退出；3日未达到0.5R收盘浮盈则下一开盘退出；2R减仓约1/3股数，剩余跟踪最高收盘减2 ATR，重复信号不续期。
- 默认8个交易日，优化候选5/8/10日；含入场日最多14个自然日。期限事前计算，预定到期按当日收盘减滑点假设卖出。停牌时保留最后估值，记录延期并在下一个可交易开盘重试。
- 从净值高点回撤8%后，余下回放的新仓风险预算永久减半；回撤15%停止新增，已有退出继续。默认永久暂停；另一个预先固定的优化候选是暂停后的20个完整交易日结束、空仓、前日QQQ在MA50上方且20日涨幅为正后重启，重启前10个交易日新仓风险减半。重启只重置风险控制阶段的参考高点，不重置净值、历史回撤或累计收益，15%不是全账户最大回撤上限。分段测试则是明确重新初始化的独立账户。
- 市场过滤候选：QQQ低于MA50时新仓风险再减半，总股票仓上限50%；不开过滤则不受这一条限制。
- 买入只使用已结算现金。卖出款进入待结算队列，2024-05-28起T+1，此前T+2；未结算款仍计净值，不能立即循环买入。借款绝不允许。

固定费用情景为每股0.005 USD佣金、每笔最低1 USD，卖出额另加0.5bps，单边滑点基线10bps；这是可修改的示例费率，不是某家券商或全历史准确费率。另测25/50bps单边滑点。收益不含分红、税、汇兑和闲置现金利息。

## 选参纪律

84个候选：前三类技术信号×量比1.5/2.0×5/8/10日×开启/关闭市场过滤×永久暂停/20交易日冷却后恢复共72组，另加rotation的10/20日动量×5/8/10日持有×开启/关闭市场过滤共12组，rotation固定20日冷却。固定风险预算不根据后段表现改动。

训练截至2022-12-30，分2019—2020和2021—2022两段独立账户；每段至少15个完整回合才有资格。训练评分是两段平均“CAGR + 0.5×最大回撤负数”，最终排序得分各取自身评分与同类信号/市场过滤参数组中位数的一半。使用复合评分而非只追累计收益，避免一个高收益、高失控风险的参数自动占榜首。

训练函数只接收训练截止日及以前数据。参数锁定后分别评估2023—2024、2025—研究截止日以及全期。另保留每类策略在训练期选出的冠军，不能根据后段重新决定总冠军。若某类没有足够交易，训练排名仍记录，但不冒称得到合格冠军。

15,000/50,000/150,000 USD ×10/25/50bps成本情景，5个信号星期分组、个股贡献、扣去前5笔最大盈利后的利润算术，都只作选择后的诊断。扣除贡献不等于重新跑一个排除这些交易的策略。全期停仓规则连续生效，各分段独立账户的收益不能直接相乘解释全期结果。

所有旧历史反复研究均为开发验证。本轮不宣称真实独立样本外或“全美股最优”。QQQ/SPY基准是100%投资的拆股调整价格收益，不含分红费用；应同时查看策略平均仓位，不能把总收益差直接称为纯选股超额。

## 可审核结果

每次报告包含配置/参数、代码和输入数据SHA256、逐股覆盖日期；优化保存实验声明、84组训练分数、锁定参数、各策略分段指标、逐笔成交、完整回合、未平仓、拆股/超期审计、资金/滑点压力测试、收益集中度和净值图。源码和测试通过不等于策略盈利被证明。

META历史接回2022-06-09以前的FB；XYZ接回2025-01-21以前的SQ。边界由发行人公告核实，旧代码在边界之后的数据一律不能拼入，防止代码复用混入其他证券。PANW、DASH等仍有供应商历史覆盖不足，逐股起点在来源报告中披露，不能当成真实IPO日期。

实验迭代记录：永久暂停基线全期回放在2021年停仓。随后加入固定冷却重启规则，扩为72组训练候选；旧36组运行中止，未将其结果包装为最终实验。该设计已受基线回放启发，所以所有后续区间继续标为开发验证。

第二次迭代：三类技术策略选出的回撤代理全年化仅约2.64%，触发稀疏。读取这些开发结果后新增12组连续相对强度轮动候选；增加交易机会是算法变更，不能宣称新规则在已查看时期得到独立样本外验证。最终实验一并保存所有84个候选。
